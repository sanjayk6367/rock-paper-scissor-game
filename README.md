# Rock Paper Scissors Game 🎮

## 🚀 Live Demo

[Play Rock Paper Scissors Game](https://sanjayk6367.github.io/rock-paper-scissor-game/)

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## 🚀 Features

* 🪨 Rock, Paper, and Scissors gameplay
* 🤖 Computer generates a random choice
* 🏆 Winner and loser detection
* 📊 User and computer score tracking
* 🤝 Draw detection
* 💬 Dynamic game result messages
* 🖱️ Interactive choice selection
* 🎨 Simple and responsive user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 How to Play

1. Choose one of the three options:

   * Rock 🪨
   * Paper 📄
   * Scissors ✂️
2. The computer randomly selects its choice.
3. The game compares your choice with the computer's choice.
4. The winner is displayed on the screen.
5. The score is updated automatically.
6. If both choices are the same, the game results in a draw.

## 🧠 Game Logic

The computer's choice is generated randomly using JavaScript.

The game compares the user's choice with the computer's choice and determines whether the user wins, loses, or the game is a draw.
